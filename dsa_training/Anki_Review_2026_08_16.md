# Anki Review - 2026-08-16

## Spaced Repetition (10 mins)

Reviewed the following concepts today:
- Backtracking: Use a `visited` set or modify the array in place to avoid revisiting cells.
- Time complexities for DFS on a grid: `O(N * 3^L)` where N is number of cells and L is length of the word (since we don't go back where we came from, it's 3 branches usually).
- Prefix trees (Trie) can be used to optimize finding multiple words in a grid (Word Search II).
