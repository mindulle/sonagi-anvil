# Jump Game (LeetCode 55)

## 문제 설명
- 주어진 배열 `nums`의 각 요소는 그 위치에서의 최대 점프 길이를 의미함.
- 첫 인덱스에서 시작하여 마지막 인덱스에 도달할 수 있는지 판단.

## 핵심 전략 (Greedy)
- 현재 위치까지 도달할 수 있는 가장 먼 거리를 유지(`max_reachable`).
- 배열을 순회하면서 도달 가능한 인덱스를 업데이트.
- 현재 인덱스 `i`가 `max_reachable`보다 크면, 더 이상 진행 불가하므로 `False` 반환.
- `max_reachable`이 마지막 인덱스 이상이 되면 `True` 반환.

## 시간/공간 복잡도
- 시간: O(n)
- 공간: O(1)

## 엣지 케이스
- `[0]` → 시작하자마자 도달 → `True`
- `[0, 2]` → 첫 위치에서 0이므로 이동 불가 → `False`
- `[1, 0, 1, 0]` → 중간에 0으로 막히는 경우 → `False`
