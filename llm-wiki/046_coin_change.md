# 046 Coin Change (LeetCode 322)

## 엣지 케이스 및 오답 노트
- **엣지 케이스 1**: `amount`가 0일 때. 예외 처리 혹은 DP 테이블 초기값을 `dp[0] = 0`으로 설정하여 커버.
- **엣지 케이스 2**: 동전으로 `amount`를 만들 수 없는 경우. DP 값을 무한대(`float('inf')`)로 두고, 순회 후에도 무한대라면 `-1`을 반환해야 함.
- **핵심 패턴**: Bottom-Up DP. `dp[a]`를 금액 `a`를 만들기 위한 최소 동전 개수라 할 때, `dp[a] = min(dp[a], 1 + dp[a - c])` (단, `a - c >= 0`).

## 시간/공간 복잡도
- 시간 복잡도: O(amount * len(coins))
- 공간 복잡도: O(amount)
