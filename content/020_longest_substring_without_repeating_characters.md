# Prompt
"문자열 내에서 반복되지 않는 가장 긴 부분 문자열의 길이를 찾으세요."

# Buggy Code
(모델의 답변 요약)
"모든 부분 문자열을 생성하고, 각 부분 문자열이 반복되는지 확인하여 가장 긴 것을 고릅니다. 이 과정은 중첩 반복문을 사용하여 O(N^2) 이상의 복잡도를 가집니다."

# Solution
### 1. Time Complexity (Nested Loops)
**문제점:** 중첩 반복문을 사용하는 방식은 비효율적입니다.
**수정:** **Sliding Window** 기법과 해시맵(HashMap)을 활용하여 O(N) 복잡도로 해결해야 합니다.

### 2. HashMap for Sliding Window
**수정:** 해시맵에 각 문자의 가장 최근 인덱스를 저장하여, 반복되는 문자가 나오면 윈도우의 시작 위치를 효율적으로 갱신합니다.
