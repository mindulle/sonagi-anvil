# Prompt
Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.

# Buggy Code
```python
def three_sum(nums):
    res = []
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            for k in range(j + 1, len(nums)):
                if nums[i] + nums[j] + nums[k] == 0:
                    res.append([nums[i], nums[j], nums[k]])
    return res
```

# Solution
### 1. Logic Bug (치명적인 논리 오류)
**문제점:** 이 코드는 중복된 트리플렛을 제거하지 않습니다. 예: `[-1, 0, 1, 2, -1, -4]` 일 때 `[-1, 0, 1]`이 여러 번 나올 수 있습니다.
**수정:** 정렬 후 Two Pointers 기법을 사용하거나, 결과 세트를 `set`으로 처리해야 합니다.

### 2. Complexity (시간 복잡도)
**현재:** 3중 for문을 사용하므로 **O(N³)** Time Complexity를 가집니다.
**최적화:** 정렬 후 Two Pointers를 사용하여 **O(N²)**로 줄일 수 있습니다.

### 3. Ideal English Feedback
"The model's code is highly inefficient, using a triple-nested loop which results in O(N³) time complexity. It also fails to handle duplicate triplets, which is a key requirement of the 3Sum problem.
The solution should first sort the array and then use a fixed element with a two-pointer approach to find the remaining two numbers. This optimized approach reduces the time complexity to O(N²), and adding checks for duplicates ensures unique results are returned."
